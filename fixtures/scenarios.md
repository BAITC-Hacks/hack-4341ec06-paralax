# Проверяемые сценарии

Это требования к будущим исполнимым acceptance-тестам. Числовые ожидаемые значения заполняются после утверждения формулы; до этого запрещено подгонять формулу под желаемый результат.

1. **Товар в пути.** При неизменных остальных данных увеличение `goods_in_transit` не увеличивает `recommended_quantity`.
2. **Разовый крупный заказ.** Добавление единственной крупной продажи от одного обезличенного клиента вызывает отметку `one_off_sale`; регулярный прогноз не растёт пропорционально её объёму.
3. **Отсутствие товара.** Для того же ряда продаж добавление подтверждённого периода stockout увеличивает оценку упущенного спроса; скорректированная потребность выше расчёта по сырым продажам.
4. **Сезонность и рост.** На синтетической истории не менее двух сезонных циклов прогноз высокого сезона выше низкого при сопоставимом тренде; устойчивый рост нескольких периодов влияет на прогноз, одиночный скачок не считается трендом.
5. **Ручное утверждение.** Корректировка `selected_quantity` сохраняет `recommended_quantity`; до явного утверждения статус `draft`, экспорт не отправляет заказ.

Файл `planning-input.sample.json` — пример структуры и двух коротких аномальных случаев. Для четвёртого сценария нужна отдельная длинная фикстура после утверждения временного шага и модели сезонности.
