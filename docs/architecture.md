# Архитектура MVP

Стек каркаса: Python/FastAPI для импорта, расчёта и OpenAI API; React/TypeScript/Vite для UI. Числовые правила и адаптация входного контракта к Excel ещё требуют решения команды в `docs/decisions.md`.

```text
Синтетическая фикстура / импорт партнёра
    → адаптер и проверка схемы
    → нормализованные данные планирования
    → очистка разовых продаж и оценка упущенного спроса
    → прогноз по артикулу и горизонту поставки
    → расчёт количества и объяснимых факторов
    → API → UI: черновики по поставщикам
    → правка и подтверждение менеджером → экспорт
                  ↘ OpenAI: объяснение проверенных факторов
```

Контракты `contracts/planning-input.schema.json` и `contracts/planning-result.schema.json` описывают границу расчётного модуля. API и UI используют те же поля. Правила округления, классификации выбросов, сезонности и срочности фиксируются тестами и `docs/decisions.md` перед реализацией.

Числа рассчитываются локальным детерминированным модулем. OpenAI API готовит объяснение по безопасным агрегатам и готовым факторам; его вывод не меняет рекомендации. Секрет API хранится в переменной окружения на сервере. При сбое API возвращается шаблонное объяснение.

Пока нет живого приложения, `contracts/api.md` обозначает только ожидаемые операции и статусы. Текущая входная схема версии 0.1.0 предназначена для синтетического сценария и должна быть адаптирована к реальным Excel до разработки импортера; детали перечислены в `docs/spec.md`.
