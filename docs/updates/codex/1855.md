# OpenAI в общем демонстрационном репозитории

23.09.2026; владелец изменений — Codex по запросу пользователя; ветка akzhan.

- После интеграции main подключён backend.ai.explain к HTTP-маршруту объяснения.
  По умолчанию backend читает корневой `.env`, приоритет у переменных процесса.
- По явному разрешению владельца проекта демо-ключ включён в `.env` ветки.
  Текст ключа не копируется в отчёты, README или frontend.
- Синтетический UI-сценарий использует OpenAI; партнёрский IEK без разрешения
  передачи агрегатов получает резервное объяснение.
- Проверки: 64 Python-теста, Ruff, mypy, frontend checks/build. Реальный запрос
  к HTTP-маршруту: статус 200, source=openai, ai_ready=true.
- Демо: кнопка AI-объяснения после POST /api/demo/planning-runs.
- Следующий шаг: интегратор переносит изменение в main для судей.
- Блокер: раскрытый демо-ключ расходует бюджет владельца любому обладателю.
