# Задачи команды на 5 часов

## Текущее распределение и старт akzhan

По уточнению команды akzhan занимается данными (`backend/importers/`), второй
участник — интерфейсом, третий — основным backend. Имена двух других участников
пока не указаны. Распределение расчёта и OpenAI из первоначального плана ниже
требует отдельного подтверждения; оно не означает, что akzhan уже взял эти задачи.

Ветка старта: `feat/akzhan/data-skeleton`. Подготовлены список 12 Excel-файлов,
команда проверки их наличия и инструкция в `backend/importers/README.md`.
Это каркас подготовки данных; импорт и расчёт пока не реализованы.
Следующий шаг akzhan — карта колонок IEK и согласование передачи данных основному backend.

## Первоначальный план

Точка отсчёта `T0` — фактическое начало разработки. Вписать реальные имена ниже: **участник 1/UI — ___; участник 2/данные и OpenAI — ___; участник 3/API и интегратор — ___**. Если интегратором будет другой человек, исправить эту строку и сообщить всей команде. Трек выбран: автоматизация заказов поставщикам. Точное ТЗ — [`spec.md`](spec.md).

Каждый работает в своей ветке `feat/<имя>/<задача>` и отдельном клоне/worktree. Общие `contracts/` и `fixtures/` меняет участник 3. Все ссылки на PR/коммиты и фактическое время вписываются в эту страницу; задачи ниже **ещё не считаются выполненными**.

Общий каркас для старта уже содержит синтетический `fixtures/planning-result.demo.json` и типы, генерируемые из схем. Это подготовка репозитория, а не выполненная задача кого-либо из трёх участников.

## Общие контрольные точки

- Каждый час: отдельный фактический отчёт `docs/updates/<имя>/<HHMM>.md` с коммитом/PR, запущенными проверками, демо-артефактом и блокером.
- Перед PR: `git fetch origin`, `git rebase origin/main`, затем `python scripts/check.py`. Не мержить в `main` без подтверждения интегратора.
- T+240–270 мин: чистый запуск по README, проверка экспорта и работы без OpenAI API, устранение только блокеров.
- T+270–300 мин: финальный демо-прогон 60–90 секунд, питч, ссылки на личные коммиты и резервный скриншот/видео.
